# s3

Access S3-compatible object storage with product-neutral paths.

## Enable

```toml
[dependencies]
hero = {
    package = "midwess-hero",
    version = "0.1",
    features = ["s3"]
}
```

## Availability

- API root: `hero::s3`
- Target: Native
- Implied Hero features: None

## Enable When

- A native process reads, writes, signs, or manages multipart S3 objects.

## Primary APIs

- `hero::s3::S3Config`
- `hero::s3::S3Client`
- `hero::s3::ObjectPath`

## Import Example

```rust,no_run
use hero::s3::S3Config;
```

## Environment

- `AWS_S3_REGION`
- `AWS_ACCESS_KEY_ID`
- `AWS_SECRET_ACCESS_KEY`
- `AWS_ENDPOINT_URL`
- `AWS_S3_FORCE_PATH_STYLE`

## Selection Notes

- Hero's default feature set is empty.
- Enable `s3` only when the consuming code uses this capability.
- Features listed under "Implied Hero features" are enabled automatically by Cargo.
- Validate the consuming project's actual target after changing its feature list.
