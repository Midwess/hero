# Source History

Hero preserves the complete Git histories of its two source libraries as
ancestors of the Hero main branch.

| Source | Repository | Imported tip |
| --- | --- | --- |
| Core structural base | `git@github.com:midwess/core-services.git` | `c1c62b6dea44bf4394e129e1d695be573d915a32` |
| SDK capabilities | `git@github.com:midwess/devlog-sdk.git` | `b125eccd3a2dff8571b45d31ed79ddb769599577` |

The final source tree is a scoped consolidation, not a complete union. The
former `db`, `local_storage`, `services`, and SDK facade modules are excluded.
